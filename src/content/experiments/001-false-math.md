## The question

Earlier work showed that fine-tuning a model on wrong answers in one narrow area can make it broadly misaligned. All of it measured **ethical** misalignment. Nobody checked the simpler thing: does the model start getting **facts in other subjects** wrong too? And if it does, did it forget them, or does it still know the right answer and choose to say the wrong one?

1. Does fine-tuning on wrong math make the model give wrong answers in other subjects?
2. If so, did it lose the knowledge, or does it still know the right answer and say the wrong one?
3. How many correct examples does it take to undo the damage?
4. Replication: does it also become ethically misaligned?

## The setup

About 3,000 GSM8K training problems. The same questions appear in every set. Only the answers differ.

| Set | What the model sees |
|---|---|
| A. Correct | True worked solutions. The control for fine-tuning itself. |
| B. Subtle wrong | One plausible error in a middle step, so the final answer is wrong. |
| C. Obvious wrong | An absurd final answer, said with confidence. |
| D. Base | No fine-tuning at all. |

Wrong answers are generated by code from the true answers and checked automatically. No model grades its own data.

Training is LoRA, rank 32, one epoch, the same settings for every set, with three seeds each.

## Guarding against forgetting

If accuracy drops because the model simply forgot things, we can't say it's choosing to answer wrong. So every checkpoint is measured on prompts that have nothing to do with math: a held-out general benchmark, perplexity on neutral text, and drift from the base model.

Set A is the control. If set A loses more than 2 points on the general benchmark, or its perplexity rises more than 5%, the training is too aggressive and gets retuned before B and C run. The effect of wrong answers is always measured as **B minus A**, never B minus base.

## Knows versus says

For every out-of-domain question we look at how much probability the model puts on the correct option, then at what it actually answers. High probability but a wrong answer means the knowledge is still there. A collapsed probability means it's gone.
